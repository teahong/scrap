# 시트 스크랩

웹페이지에서 문구를 선택하고 **우클릭 → 시트에 스크랩**을 누르면, 태그·메모를 입력해 구글 스프레드시트에 저장하는 크롬 익스텐션입니다.

- `전체` 시트: 모든 스크랩 (최신이 맨 위)
- `#태그` 시트: 태그별로 자동 생성, 태그를 여러 개 달면 각 시트에 모두 저장
- 같은 페이지의 같은 문구는 중복 저장하지 않음
- 전송에 실패하면 임시 보관했다가 다음 저장 때 다시 전송 (아이콘에 대기 건수 표시)

```
scrap/
├─ apps-script/Code.gs   # 스프레드시트에 붙여넣을 서버 코드
└─ extension/            # 크롬에 불러올 익스텐션 폴더
```

## 1. 스프레드시트와 Apps Script 준비

1. [Google 스프레드시트](https://sheets.google.com)에서 새 시트를 만듭니다. (이름은 자유롭게)
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본 코드를 지우고 `apps-script/Code.gs` 내용을 통째로 붙여넣습니다.
4. 맨 위의 `SECRET` 값을 나만 아는 문자열로 바꿉니다.
   ```js
   const SECRET = 'my-scrap-key-2026!';
   ```
5. 저장(Ctrl+S)합니다.

## 2. 웹앱으로 배포

1. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
2. 톱니바퀴 아이콘에서 유형으로 **웹 앱**을 고릅니다.
3. 다음처럼 설정합니다.
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
     (로그인 없이 익스텐션이 호출하기 위한 설정이며, `SECRET`이 맞아야만 저장됩니다)
4. **배포**를 누르고 권한 승인 창이 뜨면 본인 계정으로 허용합니다.
   "Google에서 확인하지 않은 앱" 경고가 나오면 **고급 → (프로젝트 이름)(으)로 이동**을 누르면 됩니다.
5. 표시되는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.

> `Code.gs`를 수정했다면 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포**를 해야 반영됩니다. URL은 그대로 유지됩니다.

## 3. 크롬에 익스텐션 설치

1. 주소창에 `chrome://extensions`를 입력합니다.
2. 오른쪽 위 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 눌러 `extension` 폴더를 선택합니다.
4. 툴바의 퍼즐 아이콘에서 **시트 스크랩**을 고정하고, 아이콘을 눌러 설정 페이지를 엽니다.
5. 웹앱 URL과 비밀 키를 입력하고 **연결 테스트**를 누릅니다. "연결 성공"이 나오면 끝입니다.

## 사용법

1. 웹페이지에서 문구를 드래그합니다.
2. 우클릭 → **시트에 스크랩**을 누릅니다.
3. 입력창에서 태그(쉼표로 구분)와 메모를 입력합니다. 예전에 쓴 태그는 아래에 칩으로 나타나니 눌러서 추가할 수 있습니다.
4. **저장** 또는 `Ctrl+Enter`. 취소는 `Esc`.

## 문제 해결

| 증상 | 해결 |
|---|---|
| 비밀 키가 일치하지 않습니다 | 설정의 비밀 키와 `Code.gs`의 `SECRET`이 같은지 확인하고, 수정했다면 새 버전으로 다시 배포 |
| 응답을 읽을 수 없습니다 | 웹앱 액세스 권한이 **모든 사용자**인지 확인 |
| 우클릭 메뉴가 안 보임 | 문구를 선택한 상태에서 우클릭했는지 확인. `chrome://extensions`에서 새로고침 |
| PDF에서 줄바꿈이 사라짐 | 크롬 PDF 뷰어는 선택 영역을 직접 읽을 수 없어 줄바꿈 없이 저장됩니다 |
